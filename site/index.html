Download & Install

NordFox 128.11.0 for macOS (Apple Silicon)
↓  Download NordFox-128.11.0-1-arm64.dmg
arm64 only (M1 and later). The app is ad-hoc signed — not notarized by Apple — so the first launch needs one extra step (below).
  1. Open the downloaded NordFox-128.11.0-1-arm64.dmg.
  2. Drag NordFox.app into the Applications folder.
  3. First launch: right-click NordFox.app → Open → confirm. Or clear the quarantine flag from a terminal: 
    xattr -dr com.apple.quarantine /Applications/NordFox.app
  4. Done. Cmd+T opens the NordFox quick-dial new tab; new windows open the retro start page.

Features

  • Source-level de-bloat — Normandy/Shield (remote experiments) and Pocket are removed from the code, not just switched off.
  • Timing-attack floor — performance.now() precision is clamped to 100 µs for all non-system callers (Firefox default: 1 ms with RFP off).
  • Nothing phones home — built without crash reporter and updater; telemetry, captive-portal pings, and remote recommendations are disabled.
  • No DRM — Widevine/EME are compiled out.
  • Private DNS — DNS-over-HTTPS via Quad9 in TRR-only mode (no system-resolver fallback), plus Encrypted Client Hello to hide SNI.
  • Anti-fingerprinting — resistFingerprinting + fingerprinting protection with letterboxing, canvas randomization, and spoofed window metrics.
  • Local-only Safe Browsing — malware/phishing lists checked locally, no per-download remote lookups.
  • Retro chrome — classic Firefox 1.x look: menu bar, boxed URL bar, square tabs, status bar, and a 2003-style start page. All in the Nord palette.

Build from source

NordFox is built from the Firefox ESR 128 source with LibreWolf patches on top, followed by NordFox's own patch set. Requirements: python3, node, Xcode Command Line Tools, Rust (brew install rust or rustup), and llvm@18 (brew install llvm@18 — the exact major matters, see FAQ). 

git clone <repo> nordfox && cd nordfox
./build.sh all        # fetch + patch + build + brand + DMG

A full build takes 30–90 minutes. Re-branding an existing build (./build.sh brand) takes seconds. To install the theme and the hardened user.js into an existing profile, run ./install.sh.

FAQ

Why Apple Silicon only?
NordFox targets aarch64-apple-darwin exclusively. Nobody has built or tested an Intel binary; the toolchain pins assume arm64.
Why are there no automatic updates?
The Mozilla updater is compiled out on purpose — an auto-update channel is also a remote-code channel. Updates ship as new DMGs; replace the app in Applications.
Why is LTO disabled in the build?
The C++ side is compiled with LLVM 18 (ESR 128's NSS bindgen needs it), while Homebrew Rust embeds a newer LLVM. Any LTO mode makes the LLVM 18 linker choke on the newer Rust bitcode, so LTO stays off until the two toolchains align.
How does this relate to LibreWolf?
NordFox is LibreWolf's patch set applied to Firefox ESR 128, plus its own source patches (extra de-bloat, tighter timing precision), a stricter user.js, Nord branding, and the retro theme. Upstream credit: librewolf.net.
Something broke on a site I need. What do I flip?
Most breakage comes from WebGL/WebRTC/service workers being off or TRR-only DNS. All of it is plain prefs — open about:config and relax the specific pref; the security/user.js in the repo documents every one.
